* Simple C++ mode for Emacs

This is a *C++* specialized version of [[https://github.com/rexim/simpc-mode][simpc-mode]].  simpc++-mode provides richer
highlighting for C++ files, and that's it.  It keeps fast opening, efficient
editing, and quick jumping.

* Usage

By package-vc install.

#+begin_src emacs-lisp
(use-package simpc++-mode
  :vc (:url "https://github.com/zHaOdANiuu/simpcpp-mode" :rev :newest)
  :mode "\\.\\(c\\|h\\|cpp\\|hpp\\|cppm\\|ixx\\|rc\\)\\'")
#+end_src
